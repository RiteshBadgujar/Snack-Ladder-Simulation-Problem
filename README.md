# 🎲 Snake Ladder Simulation Problem

A simple Java console application that simulates the classic Snake and Ladder game using random dice rolls. The player starts at position 0 and continues until reaching position 100.

## ✨ Features

- Single player simulation
- Random dice roll (1–6)
- Snake, Ladder, and No Play options
- Player position tracking
- Winning position at 100
- Console-based gameplay

## 🛠 Technologies Used

- Java
- Eclipse IDE
- JDK 8+
- Random Class
